TacticalCanvas

YOLOv8, ByteTrack, computer vision  ·  Hack the 6ix 2026

A projector-based tactics board for soccer coaches. A projector casts a pitch onto a surface, coaches move players by touching it, and the system recommends the next move, such as a cross or a coordinated press. Player tracking runs on YOLOv8 with ByteTrack over match footage.

What it taught me: model output is not the hard part. Getting tracking, projection, and touch input to agree on one coordinate system, with four people committing to the same repository over a weekend, was the real work.

Neural network from scratch

C++  ·  personal project

A fully connected neural network targeting MNIST, with forward and backward passes, softmax, and cross-entropy loss. No machine learning libraries. I derived the softmax Jacobian by hand and implemented the matrix math directly.

What it taught me: why the gradient math behind a framework call matters. Debugging backpropagation by hand made every later library I used legible instead of magic.

RAG chatbot

Python, LangChain, ChromaDB, OpenAI API  ·  personal project

A retrieval-augmented chatbot that answers questions from Wikipedia articles, using LCEL pipelines and semantic search over a vector database.

What it taught me: retrieval quality sets the ceiling for answer quality. Chunking and embedding decisions changed the output more than prompt wording did, which shaped how I approached RAG work during my internship.
